### 一、全局安装（手动）
如果你已经有 Node：

```
npm install -g openclaw@latest
```

### 二、安装后
- 运行新手引导：`openclaw onboard --install-daemon`
- 快速检查：`openclaw doctor`
- 检查 Gateway 网关健康状态：`openclaw status` + `openclaw health`
- 打开仪表板：`openclaw dashboard`

前往  [OpenClaw 中文](https://www.clawfather.cn/)

### 三、与微信链接

怕麻烦，直接跳过以上步骤，
直接下载 [Qclaw](https://qclaw.qq.com/)，白嫖 Token

在设置 ➡️ 远控通道 ➡ 选择接入的 APP
